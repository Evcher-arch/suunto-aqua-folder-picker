Версия `1.0.3` исправляет несоответствие иконки приложения и карточки RuStore.

В APK и в карточке RuStore используется один файл:
`assets/suunto-aqua-folder-icon-512.png`.
Он содержит красный треугольник Suunto, жёлтую папку и ноту.

Разрешения, Bluetooth-поведение и функции папок/USB взяты из `1.0.1-rustore`.
Изменены иконка и номер версии: `versionCode=6013011`, `versionName=1.0.3`.
Релиз `v1.0.0` сохранён.
