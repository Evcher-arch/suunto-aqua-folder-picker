# Индекс папок Aqua

На подключённом телефоне диагностика подтвердила: значения `SongDetail.path` содержат только имя файла. Наличие поля с названием path не гарантировало полного пути; предположение первой беты было неверным. Установленная Beta 4 использует отдельный снимок USB-структуры, не меняя идентификаторы или музыкальные файлы.

Снимок от 21 сентября 2026: 191 из 196 треков сопоставлен однозначно: `MUSIC/2025` — 124, `MUSIC/2026` — 56, `MUSIC` — 1, `SYSTEM` — 10. Четыре записи с совпадающими именами и одна без совпадения остаются без папок. При совпадающих именах в нескольких папках или нескольких записях каталога автоматическое сопоставление не выполняется.

## Как обновлять

Индекс требуется обновлять после добавления, удаления, переименования или перемещения файлов/папок в Aqua. Для простого выбора треков и сохранения плей-листов без изменения файлов обновлять USB-структуру не требуется, если каталог устройства остаётся прежним.

1. После изменения музыки безопасно извлеките Aqua из ПК, подключите по Bluetooth к телефону и дождитесь обновления каталога в Suunto.
2. Откройте добавление музыки → «Папки наушников», дождитесь завершения загрузки. Приложение сохранит актуальный каталог для сопоставления.
3. Снова подключите Aqua к ПК как USB-накопитель. Телефон также подключите к ПК с отладкой по USB.
4. Выполните в PowerShell:

```powershell
& 'C:\Users\ARCANA\Documents\ChatGPT\Suunto\suunto-modernization\scripts\Update-AquaFolderIndex.ps1' -Serial '55daaeae' -UsbRoot 'E:\'
```

5. Безопасно извлеките Aqua, подключите по Bluetooth и заново откройте режим папок.

Скрипт только читает файлы Aqua. Он скачивает экспортированный каталог приложения, строит новый индекс и атомарно заменяет индекс в данных приложения на телефоне. APK пересобирать не нужно. Если не все файлы найдены однозначно, скрипт остановится и сохранит предыдущий индекс телефона.

Чтобы применить только однозначные совпадения, добавьте `-AllowPartial` к команде. Несопоставленные записи останутся без папок; нулевое число совпадений всегда блокирует замену. Для текущего снимка использован этот режим. Переданный файл проверен обратным скачиванием с телефона, SHA256: `83f73a434d6be97b8ca4717c20329d9cbcabe1ccb4e1934e6b619e591685d23a`.

## Ограничения

Обновление через ПК — необходимый дополнительный шаг этой реализации, а не автоматическое чтение папок по Bluetooth. Beta 4 проверяет каждую запись по index/key/rawPath, сохраняя действительные соответствия при расширении каталога. Перемещения файлов, которые не изменяют эти значения в каталоге устройства, автоматически обнаружить нельзя; в таких случаях также нужен новый USB-снимок. Если каталог в приложении ещё старый, сначала дождитесь его обновления на шаге 1.

Наушники не содержат установленного кода этой доработки. Файлы плей-листов и прошивка не изменялись во время построения индекса. Bluetooth-способ получить настоящий каталог папок не подтверждён; это отдельное направление исследования.
