# Версия для модерации RuStore

Ветка: `codex/rustore-permissions`. Релиз: `v1.0.1-rustore`.
Пакет: `com.evcherarch.suuntoaquamusicfolders`.
Версия Android: 12L и новее (API 32, как у предыдущего APK).
`versionCode`: `6013009`. `versionName`: `1.0.1-rustore`.

## Изменения

Из манифеста удалены все девять разрешений по запросу модератора:

- `QUERY_ALL_PACKAGES`
- `READ_CALL_LOG`
- `READ_CONTACTS`
- `ACCESS_BACKGROUND_LOCATION`
- `ACCESS_FINE_LOCATION`
- `ACCESS_COARSE_LOCATION`
- `READ_PHONE_STATE`
- `MANAGE_ONGOING_CALLS`
- `BIND_NOTIFICATION_LISTENER_SERVICE`

Служба `com.suunto.connectivity.notifications.AncsService` удалена из
манифеста целиком: удаление только её защитного атрибута `android:permission`
сделало бы экспортированную службу незащищённой.

Сохранены `BLUETOOTH_SCAN` с `neverForLocation`, `BLUETOOTH_CONNECT`, доступ
к музыке и USB через системный выбор папки. Проверки наличия и включения
Bluetooth, а также разрешения «Устройства поблизости» остаются обязательными.

Убрана зависимость BLE-поиска от геолокации в трёх классах:

- `com.stt.android.bluetooth.BleScanner`: удалены предварительные проверки GPS.
- `com.suunto.soa.ble.permission.BlePermission`: сняты требования геолокации
  в проверках, специфичных для модуля наушников.
- `com.suunto.connectivity.util.LocationHelper`: сняты требования геолокации
  в помощнике BLE-сканера. Общие проверки геолокации приложения не изменены.

## Сохраняемые функции и ограничения

Изменения не затрагивают код выбора папок, USB-индекса, плей-листов,
переключателя «Выделить все» и сохранения позиции прокрутки.
Прошивка наушников не изменяется.

Обычные звонки через системное Bluetooth-подключение Aqua должны сохраняться:
ответ кнопкой, микрофон и звук управляются телефоном и гарнитурой.
Живая проверка звонков на новой сборке ещё обязательна.

GPS и запись маршрутов с телефона, чтение контактов/журнала звонков,
получение полного списка приложений и передача сторонних уведомлений
недоступны. Экраны исходного Suunto, связанные с этими возможностями,
могут остаться в интерфейсе; это не полная переработка всего спортивного приложения.
Остальные разрешения не удалялись автоматически: текущий запрос касается
конкретных девяти разрешений. Прохождение модерации не гарантируется.

## Воспроизведение сборки

Используйте `Suunto-Aqua-Music-Folders-1.0.0-unique.apk` из сохранённого
релиза `v1.0.0`, Apktool 3.0.2, Java 21, Android Build Tools 37.0.0 и Python 3.9+.
Скрипт проверяет ожидаемый пакет и минимальный API, затем применяет патч
к отдельному каталогу декомпиляции.

Запустите `scripts/build_rustore.ps1` с параметрами `BaseApk`, `DecodedDir`,
`OutputApk`, `KeyStore` и `Python`. Пароли передаются через переменные окружения
`SUUNTO_STORE_PASS` и `SUUNTO_KEY_PASS`. Для обновления установленного приложения
нужен прежний ключ подписи; ключи не публикуются в репозитории.

Скрипт собирает APK, выполняет zipalign с выравниванием библиотек на 16 КБ,
подписывает, проверяет подпись, совпадение сертификата с предыдущим APK и
отсутствие всех девяти разрешений в готовом бинарном манифесте.

## Проверка на телефоне перед отправкой

Проверки собранного APK выполнены 22 сентября 2026 года: подпись v3 валидна,
сертификат совпадает с v1.0.0, zipalign с параметром `-P 16` пройден.
В бинарном манифесте нет всех девяти разрешений и службы AncsService.
Все 35 smali-классов модуля папок совпадают с предыдущей сборкой.

SHA-256 APK:
`474e2815d11dfb08d64e3950f7dfb54e973373918b18c693fdff12dd633c4a45`.

Во время подготовки к ADB подключён только эмулятор x86, а APK содержит ARM
библиотеки. Поэтому запуск на телефоне, реальное USB и Bluetooth не проверены.

1. Установить APK поверх предыдущей версии с уникальным пакетом.
2. Разрешить «Устройства поблизости», отключить геолокацию телефона.
3. Проверить поиск Aqua, подключение и повторное подключение.
4. Обновить список папок по USB; проверить новую папку и вложенные папки.
5. Проверить выделение/снятие выделения всех треков и положение прокрутки.
6. Принять входящий вызов кнопкой Aqua, проверить звук и микрофон.
7. Проверить запуск после перезагрузки телефона и отсутствие сбоев.

## Текст для модератора

В новой версии удалены все девять перечисленных разрешений. Удалена служба
чтения уведомлений других приложений. Для поиска и подключения наушников
используются разрешения Bluetooth «Устройства поблизости», без доступа к
геолокации. Обновление списка папок USB-накопителя выполняется через системный
выбор каталога с разрешения пользователя. Приложение не получает доступ к
контактам, журналу звонков и управлению вызовами.
